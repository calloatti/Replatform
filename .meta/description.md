Allows dynamic splitting and restacking of platforms without requiring the deconstruction of buildings supported above.

Supports Emberpelts, Whitepaws platforms

2.0.2: Extra buildings support is optional. Start game, edit \Documents\Timberborn\PlayerData\Replatform.txt to add support for additional buildings not included in the default list.

### Settings:
Settings - Mod Settings (settings are saved in \PlayerData)
